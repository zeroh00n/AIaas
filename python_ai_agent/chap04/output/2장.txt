1️⃣ from openai import OpenAI 
 
설명: OpenAI 가 제공하는 라이브러리에서 OpenAI 클래스를 가져온다는 뜻 
 
역할: API 를 호출해서 모델(GPT)을 사용할 수 있게 해줌 
from openai import OpenAI 
 
2️⃣ api_key = '...' 
 
설명: OpenAI API 를 사용하려면 인증 키가 필요함 
 
api_key 변수에 API 키를 넣어 OpenAI 서버에 “나는 사용할 권한이 있는 
사람”이라고 알려주는 역할 
 
중요: 실제 배포 환경에서는 API 키를 코드에 직접 쓰지 않고 환경변수(os.environ)에 
두는 것이 안전함 
api_key = 'sk-...'  # 개인 키, 실제 배포 시 노출하면 안 됨 
 
3️⃣ client = OpenAI(api_key=api_key) 
 
설명: OpenAI 클래스의 인스턴스를 만들고 API 키를 연결 
 
역할: client 를 통해 GPT 모델에게 메시지를 보내고 응답을 받을 수 있음 
client = OpenAI(api_key=api_key) 
 
4️⃣ client.chat.completions.create(...) 
 
설명: GPT 모델에게 실제로 질문을 보내는 부분 
 
주요 옵션: 
옵션 
설명 
model="gpt-4o" 사용할 GPT 모델 지정 
temperature=0.1 답변의 창의성 조절 (0~1, 낮으면 정답 위주, 높으면 창의적) 
messages 
GPT 에게 전달할 대화 내용 
system 
모델에게 역할 지시 (예: “친절한 어시스턴트로 행동해”) 
user 
사용자가 질문한 내용 
response = client.chat.completions.create(

* api 키 관리하기 
위와 같이 소스코드내에 key 를 등록하는 것은 보안상의 이유 뿐만 아니라 1 억개의 파일에 
api 키를 등록 한 후에 key 변경이 이루어 진다면 1 억개의 파일을 수정해야 하는 등의 문제가 
발생 합니다. 
 
이런 문제를 해결하기 위해서 파이썬 개발자는 대부분 python-dotenv 라이브러리를 이용 
합니다. 
이 라이브러리는 .env 파일에 잇는 key-값 쌍을 읽어서 환경 변수로 설정해 줍니다.

from openai import OpenAI 
from dotenv import load_dotenv 
import os

response = client.chat.completions.create(

  ]   # ④ 
) 
 
print(response) 
 
print('----') # ⑤ 
print(response.choices[0].message.content)

1️⃣ from openai import OpenAI 
 
설명: OpenAI 가 제공하는 Python 라이브러리에서 OpenAI 라는 클래스를 가져오는 
부분

역할: OpenAI API 를 호출해서 GPT 모델에게 질문하고 답을 받을 수 있게 해줌 
from openai import OpenAI 
 
2️⃣ from dotenv import load_dotenv & import os 
 
설명: 환경변수(.env)에서 API 키 같은 비밀 정보를 안전하게 불러오기 위해 사용 
 
os 모듈은 운영체제 환경변수 접근용 
from dotenv import load_dotenv 
import os 
 
3️⃣ load_dotenv() 
 
설명: 프로젝트 폴더 안의 .env 파일을 읽어서 환경변수로 로드 
 
예시 .env 파일: 
OPENAI_API_KEY=sk-xxxxxxx 
load_dotenv() 
 
4️⃣ api_key = os.getenv('OPENAI_API_KEY') 
 
설명: 환경변수에서 OPENAI_API_KEY 값을 가져와서 api_key 변수에 저장 
 
이유: 코드에 직접 키를 쓰면 보안 위험 → 안전하게 관리 
api_key = os.getenv('OPENAI_API_KEY')

 
설명: OpenAI 클래스 객체 생성 후 API 키 연결 
 
역할: client 를 통해 GPT 모델에게 질문을 보내고 답을 받을 수 있음 
client = OpenAI(api_key=api_key)

6️⃣ response = client.chat.completions.create(...) 
 
설명: GPT 모델에게 실제 질문을 보내고, 답변을 생성하게 하는 부분 
 
주요 옵션 
| 옵션 | 설명 | 
|------|------| 
| model="gpt-4o" | 사용할 GPT 모델 이름 | 
| temperature=0.1 | 답변의 창의성 조절 (0 → 정답 위주, 1️ → 창의적) | 
| messages | 모델과의 대화 내용 | 
| system | 모델 역할 지정 (예: “친절한 어시스턴트”) | 
| user | 사용자가 질문한 내용 | 
response = client.chat.completions.create( 
  model="gpt-4o", 
  temperature=0.1, 
  messages=[ 
    {"role": "system", "content": "You are a helpful assistant."}, 
    {"role": "user", "content": "2022 년 월드컵 우승팀은 어디야?"} 
  ] 
) 
 
즉: GPT-4o 모델에게 “2️02️2️년 월드컵 우승팀은 어디야?”라고 물어보는 것 
 
7️⃣ print(response) 
 
설명: GPT API 가 반환한 전체 정보 출력 
 
전체 JSON 형태로, 답변뿐 아니라 토큰 사용량, ID 등도 포함 
print(response) 
 
8️⃣ print(response.choices[0].message.content)

choices → GPT 가 생성한 답변 목록 
 
[0] → 첫 번째 답변 선택 
 
.message.content → 텍스트 추출
